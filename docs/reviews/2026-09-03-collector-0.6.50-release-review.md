# Collector 0.6.50 release review

## Decision

PASS, limited to build/sign, same-run staged installation, a real Chrome reload,
and production READ_ONLY recovery validation. This review does not authorize
RUNNING on 2026-09-03 because the Android daily circuit breaker remains
exhausted and must not be reset or bypassed.

## Reviewed change

Collector 0.6.50 replaces the unsafe attempted cross-page duplicate
elimination with an explicit same-day discontinuity boundary. A first boundary
requires durable same-day completion, a partial page-one snapshot containing
only rows strictly newer than the previous watermark, no duplicate or
conflicting row, and completion within the 12-second recovery deadline. The
capture's ticks precede the boundary status in source-sequence order. Exact
lost-response retry is idempotent only while the durable boundary remains
unchanged; a retry after live advancement is rejected.

The boundary clears the JavaScript and Rust source-observation predecessor,
invalidates the partial boundary bucket, and cannot itself create a bar or an
order. Only a later complete local five-minute bucket can restore safe market
state. The atomic heartbeat remains status-only. Historical pagination still
fails closed on every cross-page source-row overlap because the page-local
occurrence ordinal is not a stable global identity.

## Independent evidence

Independent review confirmed source/package/build version 0.6.50, byte-equal
source/build extension payloads, absence of the rejected cross-page Set-based
deduplication, and atomic rejection before any durable write for conflict,
deadline and state races. The reviewer independently reran Rust format,
strict Clippy, 185 extension tests, 34 web-market tests, 17 ingestor tests,
19 local-isolation tests and diff checks; all passed.

Production READ_ONLY validation must still prove Chrome actually loaded
0.6.50, first exact PostgreSQL committed ACK within 45 seconds, continuous
sequence/delivery, zero conflict growth, a reset observation predecessor, no
partial-boundary bar, and a subsequent complete five-minute processing
triplet with zero Android/order/money actions.
