## Source-page presence

capture. Existing alarm phases run an independent bounded presence check. Only an
enabled collector's previously reviewed exact URL can be recreated, in a background
tab, after rechecking settings, remembered URL and current tab inventory. A durable
30-second cooldown and single-flight guard prevent repeated creation. Existing tabs
are never reloaded by this module; it does not click, handle CAPTCHA, generate
market facts or add browser permissions.

The reviewer independently checked URL rejection, pause/revocation during cooldown
