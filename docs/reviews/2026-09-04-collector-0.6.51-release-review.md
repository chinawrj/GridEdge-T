# Collector 0.6.51 release review

## Scope and decision history

This packet covers the 2026-09-03 stale-trade-coverage recovery, the
app-independent trusted-session dependency gate, the Android breaker boundary,
and the same-run publication path. It does not authorize live brokerage, test
orders, historical catch-up orders, CAPTCHA bypass, or safety-gate weakening.

Independent collector review initially returned FAIL because initialization
errors could reach reviewed-tab reload. The production classifier was reduced
to exact `STALE_TRADE_COVERAGE`; regression coverage proves all initialization,
delivery, exception and URL-TOCTOU paths are side-effect free. Final collector
review is PASS.

installer used an unfrozen worktree validator. A red tamper/missing-artifact
regression was added. Stage now freezes a same-build content-addressed
validator; install verifies it before any target creation or old-owner
quiescence. The corrected pre-install review is PASS.
